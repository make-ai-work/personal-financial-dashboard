Connect your Google account

Sign in with Google and saving to Google Drive need a free “client ID” from Google. You only do this once; it is not a password and it is not secret.

It ends in .apps.googleusercontent.com.
How do I get one? (about 5 minutes)
  1. Open Google Cloud Console and create a project (any name).
  2. APIs & Services › Library: enable the Google Drive API.
  3. OAuth consent screen: choose External, add yourself as a test user.
  4. Credentials › Create credentials › OAuth client ID, type Web application.
  5. Under Authorized JavaScript origins add this address:
    https://dashboard.example.com
  6. Create it, then copy the Client ID (not the secret) into the box above.
Never paste a client secret here. This app does not need one. Only the client ID goes in the box.
Permissions it will ask for
Your name and email (to sign you in), and access only to the files this app creates in your Drive. It cannot see your other files.
