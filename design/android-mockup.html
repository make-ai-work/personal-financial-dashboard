What is different in the app v1

  • No Google sign-in or setup screens. There is nothing to sign in to when data stays on the phone, so the app opens straight to the vault. The Account button is hidden. Google Drive comes in a later version.
  • Storage is private to the app. The vault is the same encrypted file as on the web, kept where other apps and the file manager cannot see it. Android's automatic cloud backup is switched off for it, so there is no hidden copy.
  • Safe saving. Each save writes a complete temporary copy first, so a crash or a flat battery mid-save cannot lose the vault.
  • Backup and restore use the phone's share sheet and a file picker. A restore asks before it replaces anything.
  • The Back button closes a dialog first, then goes to Home, and leaves the app from Home.
  • Fits the phone: room for the notch and the gesture bar, the same simplified phone layout as the web version.
  • Same everything else: Home (clocks, weather, markets, ticker), Finance, Property, Portfolio and Retirement. The ticker and weather need internet.
