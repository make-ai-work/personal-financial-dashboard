How the branches work

One codebase, three deployments. Each deployment keeps its data in a different place.

Three deployments, one codebase

The app is the same everywhere. What changes is the storage it is set up to use.

DeploymentWhere it comes fromWhere the data lives
Local or self-hosted
the working app		Branch main. Download it and run it on your own computer, or put it on any static web host.An encrypted file you keep, or your own Google Drive if you sign in with Google (with your own Google client ID).
Demo
showcase		Branch demo, updated from main, published to GitHub Pages.Made-up numbers read from demo/demo-data.json. Google sign-in is switched off and a Demo Mode button skips it. Edits are not saved.
Android
app		Built from main when a release is tagged (for example v1.0), published to Google Play.An encrypted file in the app's own storage, or your Google Drive.

Google sign-in on Android uses a client ID registered for the Android app itself, which is different from the web one. How that is set up will be decided when the Android app is built.

Rules that keep it simple

  • New work starts from main on its own branch, and comes back by pull request after the tests pass.
  • Code flows one way into demo. Nothing is ever merged from demo back into main, so the showcase can never change the real app.
  • There is one codebase. Demo mode, local storage and Google Drive are settings inside main, not separate copies of the app. The publish workflow in main only runs when the demo branch is updated, so ordinary work never changes the public site and the two never drift apart.
  • Android is built from main on a release tag. It has no branch of its own.
  • Your data never lives in the repository. Only the demo's made-up numbers do. Encrypted data files are ignored by git, and Google Drive copies stay in your own Drive.

Run your own copy

Download or clone main, then run npm install and npm start (the local-run command is coming in the next step). To host it somewhere else, build it with npm run build and upload the dist folder to any static host. To save to your own Google Drive, set up your own Google client ID on the first screen.
